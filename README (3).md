# tg-mailer

Рассылка по чатам от имени Telegram-аккаунта (Telethon) с панелью управления в обычном боте:
шаблоны (со спинтаксом `{привет|здравствуйте}` и `{title}`), список чатов, паузы, запуск/стоп.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # впиши API_ID, API_HASH, BOT_TOKEN, ADMIN_IDS
python bot.py
```

Дальше: напиши боту `/start` → «🔑 Аккаунт» → войди по номеру телефона.

## Важно

- `.env`, `mailer.db` и `*.session` содержат доступ к аккаунту — **не коммить их** (уже в `.gitignore`).
- Репозиторий лучше держать **приватным**.
- На хостинге база `mailer.db` должна лежать на постоянном диске (`DB_PATH`), иначе после
  перезапуска придётся заново входить в аккаунт.
- Массовая рассылка с личного аккаунта может привести к ограничениям. Не ставь паузы меньше 20–30 сек.
